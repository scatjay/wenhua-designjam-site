步驟六步做完這一份

每一步是一張卡片，點標題可以收合或展開。Figma 的按鈕怎麼按，W11 的學習單都寫了，這裡不重複。

1在 Figma 補畫至少兩張畫面約 50 分鐘

用你 W11 的那個 Figma 檔，補畫「開始、玩、結果」裡的任兩種（可以從畫面包複製改，也可以自己畫）。不知道畫什麼，回答三個問題：玩家一打開看到什麼？做事的時候畫面長什麼樣？做完看到什麼？畫好後，每一張都用 Export 匯出成 PNG。
做完的樣子：Figma 檔裡多了至少兩張畫面，你有一組 PNG。

Figma 的複製、改字、改色、Export、Share 步驟：看 W11 學習單。Share 裡 Anyone 那一列要是 can view。手機版 Figma 只能看，這一步請用電腦。

2從你的樣板取出整份 JSON約 5 分鐘

打開你的樣板頁，找到讓你取出或貼回資料的地方（解謎、節奏、潛行、談判按「我要改做」→「取出目前的資料」），把整份 JSON 複製出來。

做完的樣子：你複製了整份 JSON（還不要貼給任何人）。

3剪出「規則」那一小段約 5 分鐘

不要整份貼給 Claude，只剪「規則」那一段：

解謎某一題謎（例如「問神」那一題，在 puzzles 裡 type 是 oracle 的那一筆）
走讀rules、flags
卡牌rules、relations
經營actions、customers
故事rules、flags_init
節奏judge、score
拼接place_rules、score_rules
跑酷on_hit、lives、stamina
塔防、爬塔versions 裡面的 culture，再往下的 rules（塔防也可以剪 nights）
潛行、談判versions 裡面的 rule，再往下的 rules 或 actions

做完的樣子：你有一小段（幾十行以內）要貼的文字。

4請 Claude 找出規則的毛病約 15 分鐘

到 claude.ai，開一個新對話，把下面指令貼上，再把你剪出的那一小段貼在指令後面，送出（1 則訊息）。手機的 claude.ai 也可以，要點右下的送出鈕，按 Enter 只會換行。
做完的樣子：Claude 在約半分鐘內列出最多 3 點，每點寫「問題」和「怎麼改」。把這一輪截成一張圖。

給 Claude 的指令（找毛病）
我在做一個小遊戲，遊戲資料是 JSON。下面是其中一段規則。請你「只讀這段文字、不要改任何檔案」，幫我找出這個規則哪裡會卡死或不合理，最多列 3 點，每一點寫「問題」和「怎麼改」。

（把你剪出的那一小段規則貼在這一行下面）

它的建議不一定對。老師實測一次：它抓到了「香燒完會卡住」「笑筊的條件沒寫清楚」這類真的有道理的地方，但也建議了樣板根本沒有的欄位名稱（例如 solveMode、laughResetOn）；那種欄位加了也不會有作用。採用前，先對照你 JSON 裡真的有的欄位。

它也可能把《小封神》的人物說錯、或編出書裡沒有的情節。看到不確定的，就標「待查」，不要直接放進作品，W15 會一起檢查。只貼規則的一小段，不要整份貼，也不要貼整份 HTML。

免費版碰到「5 小時訊息上限」時，回覆會被截斷，視窗會寫重設時間；等到那個時間，或改天做。

5只改一條，載入你的樣板玩一輪約 35 分鐘

從 Claude 列的 3 點裡只挑一點來改（太大的建議，其他寫在筆記就好）。你可以自己改 JSON，也可以在同一個對話貼下面這句，請它只改那一個地方。把改好的那一段放回你整份 JSON 裡，貼回樣板頁（解謎是「載入我的版本」，其他樣板的按鈕名稱略有不同，例如「載入我的 JSON」），玩一輪。
做完的樣子：載入後沒有紅字，能走完一個流程。

給 Claude 的第二則（請它只改一處）
我決定只改你列的第（　）點。請照你的建議修改這一段 JSON，只改那一個地方，其他完全不要動，回我完整的一段 JSON，放在一個程式碼區塊裡。

出現紅字？樣板會用白話寫出哪裡有問題（例如「某某指到不存在的線索」）。把紅字原樣貼回給 Claude，說「請修這個」（這是你的第二則；這週最多送兩則）；還是不行，回到你原來的 JSON，重新只改一處。

Claude 回的如果是整份新 JSON，先確認它沒有改到你沒要它改的地方；覺得怪，就用你原來的 JSON 自己改。

6寫一句改動句約 5 分鐘

照這個句型寫一句：「＿＿原本＿＿，我改成＿＿，因為＿＿。」例如：「問神原本是 3 炷香，我改成 2 炷，因為我想讓玩的人要更小心地選問題。」
做完的樣子：你有一句說得出「改了哪條規則、為什麼」的話。

出處標示欄存版本時填三格

每週至少寫一次；換規則的版本一定要寫（這一週你就是換規則）。很短就好，目的是讓你自己看清楚哪些是你決定的。在這一頁下方的填寫區（或樣板頁的「📒 我的紀錄」）填。

  1. 這一版裡，哪些部分交給了 AI？從填寫區挑（可以多個）；沒有用 AI 就勾「沒有用 AI」。
  2. 這一版裡，哪一兩處是你自己決定的？一句話就好；想不到就寫「沒有」。
  3. 本週那一句。填寫區會顯示題目，照題目用一句話回答。

「為什麼這樣決定」那一格可以不填。你寫的內容只留在自己的瀏覽器。

先綁定你的編號，這裡才會出現填寫區。

檢核交之前，自己對照五點

  • 1Figma 多了至少兩張畫面，並匯出 PNG；Share 裡 Anyone 是 can view。
  • 2貼給 Claude 的是規則的一小段，不是整份 HTML。
  • 3內容 JSON v1 載入後能玩一輪，沒有紅字。
  • 4有一句改動句，說得出改了哪條規則、為什麼。
  • 5附了 Claude 的截圖，填了出處標示欄、附了檢核截圖。

怎麼交：到 flipclass 這份作業，貼上 Figma 連結、貼上你的內容 JSON（文字貼在留言，或存成 .txt 上傳），並上傳 PNG、Claude 截圖和檢核截圖，再寫上那句改動句。連結打不開，視同未繳交。
