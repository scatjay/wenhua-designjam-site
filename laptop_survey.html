帶筆電意願調查

這學期用 Claude Pro 做企劃與實作，帳號會分階段發放。能固定帶筆電來上課是第二個月優先發放的條件之一—— 填這個讓我們排優先序，跟作業成績、出席都沒有關係，純粹是設備調查。已經填過的話這裡會直接顯示你填過的內容，不用重填。

為什麼一定要自己的筆電 E204 電腦教室的電腦裝了還原卡，每次重開機都會清空——Claude Code 的登入、設定、更新到一半都會被還原掉。自己的筆電才留得住這些設定。
VNC／SSH 是什麼 VNC：像螢幕分享，老師可以直接看到、操作你的整個桌面，用來示範怎麼設定／除錯。 SSH：比較技術性，不用看你的畫面，直接讓老師端的 Claude Code 跟你的 Claude Code 連線協作。 不管哪一種，每一次連線前都要你在自己電腦上按同意才會進來，你也隨時可以拒絕某一次連線、或事後整個撤回意願。
