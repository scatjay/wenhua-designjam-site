先知道三件事

  • 1不要貼真實姓名、學號。AI Studio 免費版放進去的內容，可能被拿去改進產品。
  • 2AI 不是複印機，它會重寫。它做出來的是一個 AI Studio 專案（不是單一個 HTML 檔），而且你的樣板頁上的助教與「📒 我的紀錄」不會跟著過去。
  • 3AI 說「都照圖做了」，不等於真的照圖。所以每改一次，都要自己點一遍。

步驟三步做完這一份

每一步一張卡片，點標題收合或展開。AI Studio 建議用電腦做。

畫用 Claude 接 Figma，畫 3–5 個畫面＋流程圖約 30 分鐘

第一次要先到 claude.ai 連接器設定頁連上 Figma（跳兩次核准，都按「允許一次」）。頁面不會只有單頁：先想好畫面怎麼串起來（流程），再畫每個畫面的圖面。範例區有 12 個樣板可以複製一份來改（準備中）。再把下面指令貼給 Claude，把【　】換成你的。

給 Claude 的指令（畫畫面）
請用 Figma 連接器，在我的 Figma 檔【貼上你的 Figma 檔網址】新增一個頁面叫「W12 介面」，依我上週的單頁企劃，畫 3 到 5 個前後銜接的手機畫面（寬 390）。
我的企劃：樣板是【樣板名】，題名是【題名】，我想讓玩的人【那一句感覺】。
畫面順序：開始畫面 → 主畫面 → 事件或選擇畫面 → 結果畫面 →（再玩一次）。每個畫面標上編號和名稱；按鈕上的字寫清楚，並說明每個按鈕會跳到哪一個畫面。
最後再畫一張「畫面流程圖」：框是畫面，箭頭是按鈕跳轉。
每次修改後，在畫面框外的「Claude 協作日誌」文字框最下面追加一行：日期時間｜我請你做的事｜你改了什麼。
所有文字用繁體中文，不要用真實姓名或學號。畫好後，列出每個畫面的名稱和跳轉清單給我。

做完的樣子：Figma 裡有 3–5 個畫面和一張流程圖；畫面旁有一個「Claude 協作日誌」，每改一次多一行。

做匯出 PNG，交給 AI Studio 做成可以點的版本約 35 分鐘

Figma 用 Export 匯出每個畫面和流程圖的 PNG；到 aistudio.google.com/apps 開新專案，名稱是「你的樣板＋題名」，上傳全部 PNG，貼下面指令。AI 復述完，你對照 Figma 說「對」，它才開始做；生成要等好幾分鐘，不要重整、不要重送。

給 AI Studio 的指令（先復述，再做可點版本）
我附上幾張手機畫面和一張畫面流程圖。請先用文字告訴我：每個畫面叫什麼、有哪些文字和按鈕、每個按鈕會跳到哪一個畫面。先不要寫任何程式，等我說「對」再往下。
我說「對」之後，請做出可以點的版本：所有按鈕的跳接都要做出來。畫面上的文字、顏色、版面照我附的圖，一個字都不要改，也不要多加沒有的畫面。

做完的樣子：預覽打得開，每個按鈕都跳到對的畫面，文字跟你的 Figma 一樣；把預覽截圖貼進同一份 Figma 的「階段成品」區（放在 Claude 協作日誌旁），標「階段 1 可點版本」。

改同一個專案，依序改三種約 40 分鐘

還是同一個專案，不要開新的。三種修改依序做，每次：貼指令、等它改完、從頭點一遍；改完把預覽截圖貼進 Figma 的「階段成品」區（標「階段 2／3／4」），再在 Claude 協作日誌記一行。

改 1　讓核心玩法成立。改完自己照三問玩一輪：能從開始一路玩到結果嗎？輸贏或分數的變化對嗎？按「再玩一次」會從頭開始嗎？

給 AI Studio 的指令（改 1：玩法）
請把目前的專案做到可以從開始玩到結果：輸贏或分數要真的會變，結果畫面要顯示出來，結果畫面的「再玩一次」按下去要從頭開始。其他畫面、文字、顏色都不要動。

改 2　整理介面。對照你的 Figma，至少有兩處一致。

給 AI Studio 的指令（改 2：介面）
請把按鈕、標題列、字級、顏色統一成我 Figma 裡的樣子，按鈕要有按下去的狀態（變色或縮一下）。已經做好的玩法、文字和畫面跳接都不要動。

改 3　自選一個功能。例如新事件、失敗後重試、計時、道具。

給 AI Studio 的指令（改 3：自選功能）
請在目前的專案上只加一個功能：【你要的功能，例如：新事件／失敗後重試／計時／道具】。其他畫面、文字、顏色和已經做好的玩法、跳接都不要動。

做完的樣子：三種修改都做完，每次都點過；Figma 的階段成品區有 4 張圖（階段 1 可點版本，階段 2、3、4 各一種修改）。之後 W14、W16 都回這個專案接著做。

助教和 AI 助教聊一聊

點右下角的「問AI助教」，從「你的畫面裡最好玩的那一刻是什麼？」聊起，至少聊 3 輪（你說一次、助教回一次＝1 輪）。聊夠了，助教會把你的話整理成一句，按「對，就這樣」。討論佔這份作業的一半；助教不打分數，老師會讀。

聊完畫面會出現一張「助教結果卡」（上面有完成碼，不會顯示你的編號），把它截圖，連同兩個連結一起交。

檢核交之前，自己對照三點

  • 1預覽打得開，每個按鈕都跳到對的畫面。
  • 2在同一個專案做了三種修改，每次都點過一遍。原本的畫面沒有被改壞，Figma 的階段成品區有 4 張圖。
  • 3兩個連結別人打得開：AI Studio 按 Share，General access 改 Public；Figma 按 Share 改 Anyone with the link: can view。用無痕視窗貼上連結試一次，會先要你登入 Google，登入後看得到才算成功。

交件：Figma 連結、AI Studio 連結、一張「助教結果卡」截圖。

卡住了常見的卡住與解法

生成失敗，或預覽說環境不在（例如「Failed: retrying…」）
同一則指令再送一次；還是不行，按那次回覆下面的「Restore」回到上一版再試。
出現「maximum number of cloud projects」（雲端專案數達上限）
AI Studio 能開的專案數有上限。回到左側「My apps」，開舊的那個專案繼續做，不要再按「New app」；之後每一週也都沿用同一個專案。
Claude 連不上 Figma，或一直跳視窗
核准視窗會跳兩次，兩次都按「允許一次」。還是不行就回第 1 步，把 Figma 連接器中斷再連一次。
Claude 說額度用完了
等它重設，或請它一次只畫一個畫面，也可以自己在 Figma 動手畫（畫面不用完美）。
Claude 畫的畫面不對
一次只說一件事請它改；一直改不好，就自己在 Figma 動手調。
生成很久像卡住
不要重整、不要再送；先想好下一則要改什麼功能。
預覽空白或出錯
截圖；按每次回覆下面的「Restore」回到上一版再試。
找不到專案
左側「My apps」（不在首頁）。
AI 說「都照圖做了」但畫面不一樣
請它對照圖再改一次；改壞了就按「Restore」回到上一版。
AI 復述的畫面跟 Figma 不一樣
在第 3 步就請它改正，再進第 4 步。
看到 API、金鑰字樣
先不用理；如果它真的要你選金鑰，停下來問老師。AI Studio 的模型名稱可能和老師示範的不一樣，以你自己的畫面為準。
側欄廣告「Unlock …」
不要點。
免費額度用完
隔天再做。
進階任務（自願，加分，不扣分）

不想做可以直接略過，上面的主線一樣能完成。

選做 A：樣板規則檢查（壞資料三種）。把樣板的整份 HTML（在電腦的 Chrome 打開樣板，按右鍵「檢視網頁原始碼」，Ctrl＋A、Ctrl＋C）連同你的畫面一起交給 AI Studio 重做外觀，再檢查它有沒有偷偷改掉規則：①玩一輪，新專案能走完嗎？②載入原樣板的 JSON（把樣板網址最後的 .html 換成 .json），再「取出目前資料」，看資料有沒有少。③故意把 JSON 改壞三種（把某個道具的 "clue" 改成 "不存在"；把某個組合的 "gives" 改成 "不存在"；把某題 solveWhen 裡的問題名稱改成 "不存在"），一次一種，先在原樣板、再在你的新專案「載入我的版本」，看會不會被擋。把結果寫成：原樣板擋了幾種（0–3）／新專案擋了幾種（0–3）／有差異的寫在哪裡。有差異不是失敗，那就是要學到的。不是解謎樣板的同學，改成你的樣板 JSON 裡「指到不存在的東西」的三處；不確定就問老師。

樣板：故事・走讀・解謎・經營・卡牌・節奏・潛行・談判・塔防・爬塔・拼接・跑酷

選做 B：看看 AI 做出來的專案裡面長什麼樣子。在你的 AI Studio 專案按上方的「Code」，左邊會有檔案清單。找到存放資料的那個檔（例如 puzzleData.ts），對照你自己的 JSON：同一個人物名字、同一句台詞是不是都在？只要看，不用改、不用安裝任何東西。
