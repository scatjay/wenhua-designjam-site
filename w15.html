先知道五類來源怎麼標

作品裡每一樣東西（人物、台詞、地點、規則、畫面），都可以標它從哪裡來。標示是邀請，空白不扣分；老師看的是你有沒有「知道哪些是自己加的」。

原著書裡有，而且你知道在哪裡（例如《小封神》哪一段）
民間說法廟裡、長輩、傳說裡這樣講，但不一定寫在書裡
工坊創作書裡沒有，是你或我們加的
遊戲設計為了好玩而做的規則、數字、機制
田野所得你親眼看到、親耳聽到、親手記下，或問當地人問到的

一個提醒：玄天上帝、媽祖等現在還有人在祭拜。可愛可以，不嘲笑；想諷刺，就指向制度，不指向信仰本身。

步驟六步做完這一份

每一步是一張卡片，點標題可以收合或展開。Figma 的按鈕怎麼按，W11 的學習單都寫了，這裡不重複。

1回頭看同學怎麼玩你的版本，挑一件要修的事約 5 分鐘

看看 W14 的同學試玩紀錄（他卡在哪、笑了沒、說了什麼），挑一件你這週要修的事，寫成一句話。
做完的樣子：你有一句「我這週要修的是＿＿」。

2在 Figma 收尾美術約 40 分鐘

開你的 Figma 檔，只做兩件事：選一組三色（主色不超過三個）、字體固定兩種以內，字級夠大（手機看得清楚）。每一張畫面都套同一組，看起來像同一個遊戲。
做完的樣子：你的畫面放在一起，看起來像同一個作品。

Figma 的改色、改字、Export、Share 步驟：看 W11 學習單。

3放一個現場細節，並標來源約 15 分鐘

挑一個你自己看到、聽到、問到或親手記下的東西，放進作品：可以是一張照片，也可以是一句話。在畫面的角落用小字標它的來源（五類裡的一類，通常是「田野所得」）。照片不要拍到別人的臉，廟裡不要拍神像；那種情況改用文字或手繪。沒有走讀的同學：用一個你在校園或住家附近親眼看過的東西。
做完的樣子：你有一個現場細節，畫面角落標了來源，並寫好一句「它是在哪裡看到、聽到或問到的、對當地人代表什麼」。

4自己寫一張人物小卡，請 Claude 只檢查矛盾約 35 分鐘

先寫小卡：挑你作品裡一個人物，寫 3 行：①他是誰；②你確定的事（從書、課堂、或問到的來）；③不確定的，寫「待查」。再挑他的一句台詞。
再請 Claude 檢查：到 claude.ai 開一個新對話，貼下面的指令，把小卡和那句台詞貼在對應的位置，送出（1 則訊息）。手機的 claude.ai 要點右下的送出鈕，按 Enter 只會換行。
做完的樣子：Claude 約半分鐘內回覆；你把這一輪截成一張圖。

給 Claude 的指令（只檢查矛盾）
下面是我作品裡一個人物的小卡（只有我確定的資料），和我寫的一句台詞。請你「只指出」這句台詞有沒有跟小卡矛盾；小卡沒寫到的事，不要補充、不要猜，也不要改寫台詞。最多列 3 點，每點寫「哪裡矛盾」。如果沒有矛盾，就回答「沒有矛盾」。

人物小卡：
（把你寫的小卡貼在這一行下面）

台詞：
（把那一句台詞貼在這一行下面）

它說的不一定對。它可能編出書裡沒有的回目、或把人物的特徵說錯。它說的事，只要不在你的小卡上，就標「待查」，不要直接放進作品。小卡就是你的依據。

只貼一個人物、一句台詞，不要整份 JSON，用量比較省。

5改台詞，載入 JSON v2 玩一輪約 20 分鐘

依你的判斷，只改那一句台詞（或標示）。把改好的整份 JSON 貼回樣板頁（解謎是「載入我的版本」，其他樣板的按鈕名稱略有不同），玩一輪。這份就是 JSON v2。
做完的樣子：載入後沒有紅字，能走完一個流程。

出現紅字？樣板會用白話寫出哪裡有問題。把紅字原樣貼回給 Claude 說「請修這個」（這是你的第二則）；還是不行，回到 W13 的 v1，重新只改一處。

6匯出展示圖，交件約 15 分鐘

把收尾好的畫面排在一起（一個 Frame 裡放三到四張），用 Export 匯出成一張展示 PNG。Share 設成 Anyone 是 can view。
做完的樣子：你有一個 Figma 連結、一張展示 PNG、JSON v2、現場細節那一句，以及 Claude 的截圖。

出處標示欄存版本時填三格

每週至少寫一次；這一週你放進了現場細節，一定要寫。很短就好，目的是讓你自己看清楚哪些是你決定的。在這一頁下方的填寫區（或樣板頁的「📒 我的紀錄」）填。

  1. 這一版裡，哪些部分交給了 AI？從填寫區挑（可以多個）；沒有用 AI 就勾「沒有用 AI」。
  2. 這一版裡，哪一兩處是你自己決定的？一句話就好；想不到就寫「沒有」。
  3. 本週那一句。填寫區會顯示題目：你放進作品的現場細節，是在哪裡看到、聽到或問到的？對當地人來說，它代表什麼？

「為什麼這樣決定」那一格可以不填。你寫的內容只留在自己的瀏覽器。

先綁定你的編號，這裡才會出現填寫區。

檢核交之前，自己對照五點

  • 1展示 PNG 風格統一：主色不超過三個、字體兩種以內、字級夠大。
  • 2作品裡有一個現場細節，畫面角落標了來源，並寫了「在哪裡看到、對當地人代表什麼」。
  • 3台詞經過一次 Claude 檢查，它說的、小卡上沒有的事，你標了「待查」，沒有直接放進作品。
  • 4JSON v2 載入後能玩一輪，沒有紅字。
  • 5填了出處標示欄、附了 Claude 截圖與檢核截圖。

怎麼交：到 flipclass 這份作業，貼上 Figma 連結、貼上你的內容 JSON（文字貼在留言，或存成 .txt 上傳），上傳展示 PNG、Claude 截圖和檢核截圖，再寫上現場細節那一句。連結打不開，視同未繳交。
