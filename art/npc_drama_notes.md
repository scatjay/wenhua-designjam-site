## 套用規則（給接手套用的人）

1. 鍵是 `npc.name` 完整原文。同名 NPC 只列一次，**套用到所有出現處**：
   - 「公布欄上的便條（畢不了學姊）」「校史館的志工學姊」「西淮館的夜班管理員」：白天路線與夜間路線（c0／c1／c2 複製成 y0／y1／y2）都套用。

   - 「州知事的祕書」「檔案室管理員」「三郊的老帳房」「搬廟那年的木匠學徒」：主線與中西區九案（t1／t3／t6／t7 是 clone）都套用。
2. 三個特殊鍵（因為同名但內容不同，用 `@路線.站點` 區分，不是原文名字）：
   - `畢不了學姊`：只套用 campus.c4（白天終點）。
   - `畢不了學姊@campusW.w4`：夜間終點（名字也是「畢不了學姊」，但開場白與結語不同）。
   - `檔案室管理員@tw.t3`：只有 `done`。walk_route_tw.js 在 clone 之後把 t3 的 `npc.done` 覆寫成「面磚的溝數、窗框的高度」那句，所以 tw 版的 done 另列；`檔案室管理員` 本鍵的 `done` 是主線 s2 的版本（量天氣那棟、公園路）。套用時 tw 覆寫要放在 clone 之後。
3. 「銅像旁的老園丁（夜班）」名字不同，單獨列；它的 open[0]、done 與白天版不同，其餘沿用白天版文字。
4. 夜間 `w0` 與白天 `c0` 的便條台詞末尾，runtime 會再 push 一句「學姊的便條：……」（白天／夜間日記句）。我的 open 長度與原檔相同，所以 push 的位置不變，**我沒有把那些句子列進 open**，也沒有改。
5. 沒列出的欄位 = 沒改。`hints: []`、`done: ''` 的 NPC（c0、w0 的便條）不加戲，維持空。

## 疑似有事實疑慮的原句（只標示，沒有修改，我的改寫保持原意）

1. **檔案室管理員 clue／open**：「這塊地以前是拿來給神明蓋房子的」、龍王廟→學校→警察署，原檔 note 已說明只有單一來源。
2. **檔案室管理員 done（主線 s2）**：「這種面磚我只在另一棟樓看過，就是量天氣的那一棟」與 s3 的 tip「面磚同款」沒有列來源；而且九案 note 指出原測候所距武德殿約 330 公尺，路線順序要確認。tw 版 done 已避開這句。
3. **州知事的祕書 done**：「警察署以前跟我們擠在同一棟樓辦公，後來自己蓋了新樓，在南門路上」，來源未列。
4. **校史館的志工學姊 hints[1]**：「第一屆學生真的來學校開學的那一天，才被當成校慶日」幾乎直接把題目 k1 的答案講出來。原檔如此，我沒動，但這和「不在提示前說出答案」的精神有衝突，建議你決定要不要改。
5. **西淮館的夜班管理員 hints[2]／clue**：「西淮就是他爸爸的號」「兒子幫爸爸取名」，原檔 note 標 unverified（推論），提示卻用肯定句。
6. **銅像旁的老園丁（夜班）done**：「學校是一群台南人集資蓋起來的」，創辦人籍貫沒有來源，建議核對。
7. **畢不了學姊（c4）open[2]**：「整個校園擠進快十萬人」；原 note 寫的是「兩日近 10 萬人次」，用語可能被讀成同時在場，建議核對。
8. **榕樹下的老先生 open[1]**：「這個作品的名字很老，比學校老得多」，指的是詞的歷史，但作品本身創作者與涵義 note 說沒查到，容易被讀成作品很老。
9. **涼亭裡的等車阿姨 hints[1]**：「明鄭，就是鄭成功他們在台灣的那個時代」是口語概括（明鄭延續到鄭成功之後），不是錯，但不精確。note 另說傳說細節未讀到。
10. **圓環旁的路牌檢查員 open[1]**：「日治時代有七條路從這裡放射出去，每一條都有町名」，「七條」沒有來源標示。

12. **電梯學徒 hints[2]／k2**：「全臺灣目前只有這一家百貨公司有——在屋頂上」是絕對語氣；note 只說設計者待補，這句沒標來源。
13. **老圖書館員 hints**：一樓面磚、二樓橫向木板，note 已標摘要級，上線前宜補強。
14. **三郊的老帳房 open／clue**：「清冊上寫的是『產業』」「遶境的鑼已經停了」，note 說該站為骨架版、現場可驗證實物少。
15. **搬廟那年的木匠學徒 clue／hints**：門朝向與舊步口方向，題目答案本身標 unverified。

## 加戲手法對照（便於抽查）

- 話少型（檔案室管理員、老帳房、西淮館管理員、老園丁、榕樹下老先生、老工友、老圖書館員、局長、水邊看守者）：句子縮短、用停頓、括號小動作（放下剪刀、推推眼鏡、關掉手電筒）。
- 話多型（祕書、木匠學徒、校史館志工、阿姨、電梯學徒、夜跑學長、夜讀生）：離題一句再自己拉回來，或賣關子、眨眼。
- 重道理型（祕書、夜讀生、夜跑學長、守門人、老帳房）：hints 加「第一、第二、第三」或「第一筆、第二筆」，done 有結論句。
- 重感受型（便條學姊、志工學姊、木匠學徒、阿姨、電梯學徒）：被接住後情緒起伏（眼眶一紅、眼睛彎成月亮、拍手）。
- 括號小動作均不超過 12 字；無 MBTI 字樣；沒有新增真人姓名（原有的歷史人物與創辦人名字保留在原句）。
