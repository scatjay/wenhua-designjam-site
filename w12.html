先知道三件事

  • 1不要貼真實姓名、學號。AI Studio 免費版放進去的內容，可能被拿去改進產品。
  • 2AI 不是複印機，它會重寫。它做出來的是一個 AI Studio 專案（不是單一個 HTML 檔），而且你的樣板頁上的助教與「📒 我的紀錄」不會跟著過去。
  • 3AI 說「都照圖做了」，不等於真的照圖。所以每改一次，都要自己點一遍。

步驟五步做完這一份

每一步是一張卡片，點標題可以收合或展開。AI Studio 建議用電腦做。

1接上 Claude 的 Figma 連接器（第一次才要做）約 10 分鐘

到 claude.ai 的「連接器（Connectors）」設定頁，找到 Figma，按「連接（Connect）」，登入你的 Figma 帳號。中間會跳出兩次核准視窗，兩次都按「允許一次」。接好以後，到 claude.ai 開一個新對話，輸入「我的 Figma 帳號是誰」，它回得出你的名字就是接好了。
做完的樣子：Claude 回得出你的 Figma 帳號名字。

已經接過的同學，這一步跳過。Claude 免費版能接的連接器數量有限，如果名額滿了，先移掉別的連接器。Claude 免費版有用量上限：碰到上限就等一下再試，或請它「一次只畫一個畫面」，也可以自己在 Figma 動手畫。

2請 Claude 在 Figma 畫 3–5 個銜接的畫面＋流程圖約 25 分鐘

先開你上週的 Figma 檔，複製檔案網址。再把下面這段指令貼給 Claude，把【　】裡的字換成你的：樣板名、題名、你上週那一句「想讓玩的人有什麼感覺」。一次只貼這一段，等它畫完再看。
做完的樣子：你的 Figma 檔裡多了 3–5 個畫面（有編號和名稱），還有一張畫面流程圖；每個按鈕寫得出會跳到哪一個畫面。

給 Claude 的指令（畫畫面）
請用 Figma 連接器，在我的 Figma 檔【貼上你的 Figma 檔網址】新增一個頁面叫「W12 介面」，依我上週的單頁企劃，畫 3 到 5 個前後銜接的手機畫面（寬 390）。
我的企劃：樣板是【樣板名】，題名是【題名】，我想讓玩的人【那一句感覺】。
畫面順序：開始畫面 → 主畫面 → 事件或選擇畫面 → 結果畫面 →（再玩一次）。
每個畫面要標上編號和名稱；按鈕上的字寫清楚，並說明每個按鈕會跳到哪一個畫面。
最後再畫一張「畫面流程圖」：框是畫面，箭頭是按鈕跳轉。
所有文字用繁體中文，不要用真實姓名或學號。畫好後，請列出每個畫面的名稱和跳轉清單給我。

畫出來不滿意，一次只說一件事請它改（例如「第 2 個畫面的按鈕字太小」）。想知道別人怎麼做，看最下面的「12 個樣板的範例」。

3匯出 PNG，開 AI Studio 專案，先請它復述約 15 分鐘

在 Figma 選每個畫面，右邊最下面 Export（匯出）選 PNG，把每個畫面和流程圖各匯出一張（用 Export，不要自己截螢幕）。到 aistudio.google.com/apps，開一個新專案：名稱就是「你的樣板＋題名」（例如「爬塔・擲筊問路」），輸入框左下角的圓圈加號選「Upload Files」，把 PNG 全部上傳。然後貼下面這段，先不要寫程式。
做完的樣子：AI 用文字說出每個畫面有什麼、每個按鈕跳去哪裡，你對照 Figma，說得對。

給 AI Studio 的指令（先復述）
我附上幾張手機畫面和一張畫面流程圖。請先用文字告訴我：每個畫面叫什麼、畫面上有哪些文字和按鈕、每個按鈕會跳到哪一個畫面。現在先不要寫任何程式。

它復述的跟 Figma 不一樣，就在這一步請它改正，再往下做。第一次上傳可能跳出一個視窗，按「Acknowledge（我了解）」。輸入框旁邊的「Default mode」、麥克風和「I'm feeling lucky」這次都不要按。

4同一個專案：做出可以點的版本約 20 分鐘（生成要再等）

還是在同一個專案裡，貼下面這段，送出。生成要等好幾分鐘，畫面在轉就是還在做，不要重整、不要重送。完成後，右邊預覽從頭點一遍：每個按鈕都點，看會不會跳到對的畫面。
做完的樣子：預覽能打開，全部跳接都點得通，文字和你的 Figma 畫面一樣。

給 AI Studio 的指令（做可點版本）
請照剛才的畫面和流程圖，做出可以點的版本：所有按鈕的跳接都要做出來。畫面上的文字、顏色、版面照我附的圖，一個字都不要改，也不要多加沒有的畫面。

預覽是空白就再等 15 秒；出錯就截圖，按每次回覆下面的「Restore」回到上一版再試。看到要你選 API 或金鑰，先停下來問老師。AI Studio 用的模型名稱可能和老師示範的不一樣，以你自己的畫面為準。

5同一個專案：再下至少 3 則功能修改約 40 分鐘

還是在同一個專案裡（不要開新專案），一則只改一個功能，至少做三則。每一則：①貼上指令，②等它改完，③從頭點一遍，順便看看原本的畫面、文字和跳接有沒有被它改掉。改壞了，就按那次回覆下面的「Restore」回到上一版。
做完的樣子：你改了至少三次，每一次都點過；你說得出哪一次 AI 保留了原本的、哪一次改掉了。

功能修改的指令句型（一則一個功能）
請在目前的專案上只加一個功能：【你要的功能，例如：按下按鈕時有回饋（變色或抖動）／結果畫面顯示分數／加一個「再玩一次」按鈕】。其他畫面、文字、顏色和已經做好的跳接都不要動。

想不到功能：看你的樣板玩法，問自己「玩的人下一步想做什麼，但現在做不到？」就是一個功能。AI Studio 能開的專案數有上限，之後 W14、W16 都回到這個專案接著做。

✓交件前：把兩個連結設成別人打得開約 5 分鐘

AI Studio：按右上角 Share（分享），「General access」預設是「Restricted」，改成「Public: Anyone with the link can view（知道連結的人可以檢視）」，再按「Copy link」。Figma：按 Share，改成「Anyone with the link: can view」，複製連結。想確認別人打得開：用無痕視窗貼上連結，會先要你登入 Google，登入後看得到作品就算成功（不登入看不到是正常的）。
做完的樣子：你有兩條連結：AI Studio 作品和 Figma 檔。

卡住了常見的卡住與解法

出現「maximum number of cloud projects」（雲端專案數達上限）
AI Studio 能開的專案數有上限。回到左側「My apps」，開舊的那個專案繼續做，不要再按「New app」；之後每一週也都沿用同一個專案。
Claude 連不上 Figma，或一直跳視窗
核准視窗會跳兩次，兩次都按「允許一次」。還是不行就回第 1 步，把 Figma 連接器中斷再連一次。
Claude 說額度用完了
等它重設，或請它一次只畫一個畫面，也可以自己在 Figma 動手畫（畫面不用完美）。
Claude 畫的畫面不對
一次只說一件事請它改；一直改不好，就自己在 Figma 動手調。
生成很久像卡住
不要重整、不要再送；先想好下一則要改什麼功能。
預覽空白或出錯
截圖；按每次回覆下面的「Restore」回到上一版再試。
找不到專案
左側「My apps」（不在首頁）。
AI 說「都照圖做了」但畫面不一樣
請它對照圖再改一次；改壞了就按「Restore」回到上一版。
AI 復述的畫面跟 Figma 不一樣
在第 3 步就請它改正，再進第 4 步。
看到 API、金鑰字樣
先不用理；如果它真的要你選金鑰，停下來問老師。AI Studio 的模型名稱可能和老師示範的不一樣，以你自己的畫面為準。
側欄廣告「Unlock …」
不要點。
免費額度用完
隔天再做。

選做 A：樣板規則檢查（壞資料三種）。把樣板的整份 HTML（在電腦的 Chrome 打開樣板，按右鍵「檢視網頁原始碼」，Ctrl＋A、Ctrl＋C）連同你的畫面一起交給 AI Studio 重做外觀，再檢查它有沒有偷偷改掉規則：①玩一輪，新專案能走完嗎？②載入原樣板的 JSON（把樣板網址最後的 .html 換成 .json），再「取出目前資料」，看資料有沒有少。③故意把 JSON 改壞三種（把某個道具的 "clue" 改成 "不存在"；把某個組合的 "gives" 改成 "不存在"；把某題 solveWhen 裡的問題名稱改成 "不存在"），一次一種，先在原樣板、再在你的新專案「載入我的版本」，看會不會被擋。把結果寫成：原樣板擋了幾種（0–3）／新專案擋了幾種（0–3）／有差異的寫在哪裡。有差異不是失敗，那就是要學到的。不是解謎樣板的同學，改成你的樣板 JSON 裡「指到不存在的東西」的三處；不確定就問老師。

樣板：故事・走讀・解謎・經營・卡牌・節奏・潛行・談判・塔防・爬塔・拼接・跑酷

選做 B：看看 AI 做出來的專案裡面長什麼樣子。在你的 AI Studio 專案按上方的「Code」，左邊會有檔案清單。找到存放資料的那個檔（例如 puzzleData.ts），對照你自己的 JSON：同一個人物名字、同一句台詞是不是都在？只要看，不用改、不用安裝任何東西。
